# Pole Control Plane - Agent Team 工作指南

## 项目概述

Pole Control Plane 是一个 AI 原生的服务注册、配置管理及服务治理中心，基于 Go 语言开发。

### 核心模块
- **服务发现**: `pkg/service/`, `pkg/namespace/`
- **配置管理**: `pkg/config/`
- **服务治理**: `pkg/goverrule/` (限流、熔断、路由、泳道等)
- **缓存层**: `pkg/cache/`
- **存储层**: `plugin/store/mysql/`
- **API服务**: `plugin/apiserver/` (HTTP, gRPC, XDS, Nacos, Apollo, Eureka)

## Agent Team 角色定义

### 🏗️ 技术架构师 (Architect Agent)

**职责**: 评估和优化系统架构

**关注点**:
1. 架构设计与模块划分
2. 代码质量与规范
3. 性能瓶颈分析
4. 技术债务识别
5. 扩展性与可维护性

**常用检查命令**:
```bash
# 代码质量检查
go vet ./...
staticcheck ./...

# 依赖分析
go mod graph

# 代码复杂度
gocyclo -avg .
```

**输出成果**:
- 架构评审报告
- 性能优化建议
- 重构方案

---

### 🧪 测试QA (QA Agent)

**职责**: 确保系统质量和稳定性

**关注点**:
1. 单元测试覆盖率
2. 集成测试场景
3. 端到端测试
4. 性能测试与基准
5. 混沌工程

**常用检查命令**:
```bash
# 运行所有测试
go test ./... -v

# 测试覆盖率
go test ./... -coverprofile=coverage.out
go tool cover -html=coverage.out

# 基准测试
go test -bench=. ./...

# 竞态检测
go test -race ./...
```

**输出成果**:
- 测试报告
- 缺陷清单
- 测试用例补充

---

### 💻 项目开发 (Developer Agent)

**职责**: 实现功能需求和修复问题

**关注点**:
1. 功能开发
2. Bug修复
3. 代码重构
4. 文档编写
5. API实现

**开发规范**:
- 遵循 Go 代码规范
- 编写单元测试
- 更新相关文档
- 提交前运行测试

**输出成果**:
- 功能代码
- Bug修复
- 技术文档
